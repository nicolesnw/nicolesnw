#### 2. [Automated Batch Print & Mockup Pipeline](https://github.com/nicolesnw/batch-print-pipeline)
A computer vision and pre-press automation tool that prepares raw transparent PNGs for physical production.
* **Tech Stack:** Python, FastAPI, Pillow (`PIL`), React, Tailwind CSS
* **Highlights:** Auto-crops transparent alpha borders, calculates exact **300 DPI** pixel dimensions, enforces hardware print-width limits, mirrors sublimation transfer files, and renders 3 studio product mockups per design bundled into an in-memory ZIP archive.
